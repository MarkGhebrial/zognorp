# `zognorp`

`zognorp` is a program that solves sudoku puzzles. It is very fast.

I initially planned to design this algorithm on my own. I got _very_ close, but got stuck for a while.
Thanks to https://www.norvig.com/sudoku.html for getting me unstuck and for giving me clues on how to
improve my implementation.

No AI was used in the making of this project.
